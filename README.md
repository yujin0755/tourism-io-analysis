# 관광산업의 경제적 파급효과 분석 웹앱

## 1. 웹앱 사용법

1. [웹앱 주소](https://yujin0755.github.io/tourism-io-analysis/)에 접속한다.
2. **원자료 탐색** 탭에서 '기본부문 불러오기' 버튼을 클릭한다.
3. 자료가 로딩되면 산업연관표의 시트와 380개 기본부문을 확인한다.
4. 검색창에 산업 코드 또는 산업명을 입력하여 원하는 산업을 찾는다.
5. **시뮬레이터** 탭에서 산업을 선택하고 최종수요 증가액을 입력한다.
6. 계산 버튼을 눌러 생산유발액, 수입유발액, 부가가치유발액을 확인한다.

## 2. 분석 방법

2023년 산업연관표의 거래표와 투입계수 및 유발계수를 활용하여 관광 관련 산업의 경제적 파급효과를 분석하였다.

- 분석 기준: 2023년 생산자가격 산업연관표
- 분석 부문: 기본부문 380개
- 분석 단위: 백만원
- 분석 대상: 관광 관련 8개 산업
- 분석 가정: 각 산업의 국내 최종수요가 1,000백만원 증가

각 산업에 동일한 최종수요 증가액을 적용하여 생산유발효과, 수입유발효과, 부가가치유발효과를 비교하였다.

## 3. 행·열 코드 탐색 및 원자료 확인

산업연관표의 행과 열에서 산업 코드를 선택하여 교차하는 계수값을 확인하였다.

생산유발계수표에서 다음과 같은 값을 직접 탐색하였다.

| 행 코드 | 열 코드 | 확인값 |
|---|---|---:|
| 7904 | 7904 | 1.277 |
| 5820 | 5820 | 1.002 |
| 5811 | 5820 | 0.017 |
| 5500 | 5820 | 0.002 |
| 7904 | 5820 | 0 |
| 5611 | 5310 | 0.140 |

이를 통해 숙박, 여행사, 음식점, 항공운송 및 육상운송보조서비스 등 관광 관련 산업의 행·열 교차값을 확인하고 산업 간 연관관계를 탐색하였다.

※ 위 숫자는 엑셀의 물리적인 행·열 위치가 아닌 산업 코드이다.

## 5. 분석 결과

각 산업에 국내 최종수요 1,000백만원이 증가한다고 가정한 시뮬레이션 결과이다.

단위: 백만원

| 산업명 | 생산유발액 | 수입유발액 | 부가가치유발액 |
|---|---:|---:|---:|
| 숙박 | 1,904.165 | 121.834 | 878.166 |
| 일반음식점 | 2,276.136 | 216.217 | 783.783 |
| 항공운송서비스 | 1,310.890 | 588.823 | 411.177 |
| 철도운송서비스 | 1,608.803 | 131.508 | 868.492 |
| 여행사 및 여행보조 서비스 | 2,031.560 | 141.859 | 858.141 |
| 문화서비스(국공립) | 1,950.967 | 146.874 | 853.126 |
| 스포츠서비스 | 1,698.179 | 111.364 | 888.636 |
| 육상운송보조서비스 | 1,342.087 | 62.517 | 937.483 |

일반음식점은 생산유발액이 가장 높았으며, 육상운송보조서비스는 부가가치유발액이 가장 높았다. 항공운송서비스는 수입유발액이 가장 높게 나타났다.

## 6. 자료 및 검증

- 교수님 제공 2023년 산업연관표 엑셀 자료 활용
- 총 12개 시트 및 380개 기본부문 확인
- 생산유발계수, 수입유발계수, 부가가치유발계수 검증
- 최대 검증 잔차 약 10⁻¹⁵로 허용오차 10⁻⁸ 이내 확인
- 금액 단위는 백만원으로 표시

## 7. 분석의 한계 및 유의사항

본 분석은 실제 관광객 소비액이 아닌 산업별 국내 최종수요 1,000백만원 증가를 가정한 모의분석이다. 따라서 결과를 실제 경제 상황의 확정적인 예측이나 인과관계로 해석하는 데에는 한계가 있다.

자료 공개 권한과 개인정보 포함 여부를 확인한 후 공개 저장소에 자료를 게시해야 한다.
